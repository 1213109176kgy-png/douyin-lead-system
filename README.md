# 抖音获客系统

一个面向 Windows 单机使用的抖音公开评论线索整理工具。它可以按行业、产品或服务关键词检索公开视频，分析公开评论中的咨询与购买意向，并将线索保存在本机、筛选管理及导出为 Excel。

## v1.2.6 更新说明

### 新增功能

- 移除订单授权号依赖，改用随软件发布的开源本地接口服务。
- 新增独立可见的抖音浏览器采集流程：优先使用系统 Edge，没有 Edge 时自动使用软件内置 Chromium。
- 获客任务新增 IP 属地（省级）筛选，以及今日、近 3 天、近 7 天、本月等评论时间筛选。
- 任务列表新增“查看客户”，可直接跳转客户池并筛选出该任务的客户。
- 客户池新增任务、地区和最近采集时间，并按最新采集时间倒序排列。
- 视频库新增作者、任务、采集时间、真实点赞数和完整标题悬浮提示。
- 视频拆解接口失败时自动切换浏览器解析原视频；无口播的图文或配乐视频也可以继续进行 AI 拆解。
- 爆款素材库新增无水印视频下载，可播放下载结果或打开所在文件夹；重复点击时支持重新下载或直接打开文件夹。

### 问题修复

- 修复已登录抖音仍被误判为未登录的问题。
- 修复部分关键词搜索页返回 502、页面跳转或页面结构变化时反复重试的问题。
- 修复视频标题被时长替代、多个视频显示相同标题的问题。
- 修复作者为空、互动数据固定显示为 0、客户主页使用无效测试数据等问题。
- 修复视频详情接口 HTTP 500 导致“拆解失败”的问题。

### 稳定性与真实性优化

- 搜索任务增加串行队列、最小请求间隔、异常熔断和冷却保护，减少账号触发平台限制的概率。
- 只保存从真实搜索页和公开评论读取的数据；无法可靠获得的收藏数、评论总数显示为“—”，不再填充假数据。
- 登录资料使用软件专用浏览器目录，不读取用户个人浏览器资料。
- Windows 绿色包内置 Chromium 与所需运行环境，目标电脑无需预装 Edge 或 Python。

## 主要功能

- 按关键词创建获客任务，设置目标客户数、视频数和评论数
- 自动整理公开视频与公开评论中的意向线索
- 客户池按任务、意向等级和跟进状态筛选
- 视频库查看互动数据、来源线索数及原视频
- 本地 Whisper 语音转文字，结合 OpenAI 兼容接口拆解和仿写视频
- 爆款素材库保存拆解结果、标签、备注和仿写内容
- 爆款素材库支持下载无水印视频、播放视频、打开下载目录和重复下载识别
- 自定义意向关键词、分值及启停状态
- 按任务、等级、状态导出 Excel
- Cookie 与 API Key 使用 Windows DPAPI 加密后仅保存在本机
- 关键词搜索使用独立、可见的持久浏览器会话；优先调用系统 Edge，没有 Edge 时自动使用随软件发布的 Chromium
- 登录、Cookie、本地存储和缓存保持一致，不读取用户的个人浏览器资料
- 搜索任务串行执行，并带最小间隔与异常熔断；遇到验证码、异常跳转或页面不可解析时停止自动重试
- 获客任务支持按评论 IP 属地筛选，并支持今日、近 3 天、近 7 天、本月等评论时间范围

## 项目结构

- `app/`：Windows 桌面客户端、数据管理、评分、导出和 AI 工作流
- `server/douyin-local.exe`：Apache-2.0 开源抖音本地接口服务
- `tests/`：自动化测试
- `scripts/`：本地联调与界面验证脚本

## 开发环境

- Windows 10/11
- Python 3.10+
- PySide6
- faster-whisper

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -e ".[dev]"
pytest -q
python -m app.main
```

## 配置

在“系统设置”中配置：

1. 抖音网页登录状态（用于平台登录与风控校验，不再需要订单授权号）
2. DeepSeek 或其他 OpenAI 兼容 API 地址、API Key 与模型名
3. 视频拆解、仿写提示词

所有业务数据默认保存在程序目录的 `data/` 中，该目录已被 Git 忽略。
