抖音获客系统（绿色免安装版）

一、启动
1. 请先完整解压 ZIP，不要直接在压缩包内运行。
2. 双击“DouyinLeadSystem.exe”。
3. 所有数据保存在软件目录下的 data 文件夹，移动软件时请连同 data 一起移动。

二、首次设置
1. 打开“系统设置”。
2. 点击“一键登录抖音”，程序会弹出一个独立浏览器窗口，请在该窗口扫码或登录。软件优先使用系统 Edge；电脑没有 Edge 时会自动使用软件内置 Chromium，无需用户另外安装。
3. 该窗口使用本程序专用资料目录，不读取你的个人浏览器资料。系统检测到登录成功后会自动保存并关闭窗口。
4. 点击“启动并检测本地服务”。本版本使用随软件附带的开源本地服务，不需要订单授权号。
5. 登录状态使用 Windows DPAPI 加密，只能由当前 Windows 用户在本机解密。需要退出时点击“清除登录状态”。

三、获客
1. 打开“获客任务”，输入行业、产品或服务关键词，例如“销售工牌”。
2. 设置目标客户数、视频数及每个视频的评论数。
3. 可从“IP属地（省级）”下拉框选择一个地区，并选择评论时间：不限、今日、近3天、近7天或本月。抖音公开属地通常只显示到省级，例如深圳用户应选择“广东”。
4. 点击“开始获客”。系统会打开可见的专用浏览器窗口搜索公开视频，再读取公开评论，只保留符合地区和时间条件的评论，并按购买、价格、地点、咨询、联系方式等意向词评分。采集过程中不要手动关闭该窗口。
5. 结果进入“客户池”。任务列表可点击“查看客户”，直接跳转并筛选出该任务的客户。

四、导出
在“数据导出”中选择全部任务或某一条任务，再按意向等级、客户状态筛选。界面会显示预计数量。Excel 包含原评论、来源视频、命中规则、公开主页、客户列表和操作日志。

五、视频拆解与仿写
1. 在“系统设置”填写 OpenAI 兼容的 API 地址、API Key 和模型名称。DeepSeek 示例地址：https://api.deepseek.com/v1，模型：deepseek-chat。
2. 可直接编辑“视频拆解提示词”和“仿写提示词”，API Key 使用 Windows DPAPI 加密。
3. 在“视频库”点击“拆解”。系统会下载公开视频到临时目录，使用本地 faster-whisper base INT8 转写口播，再调用配置的 AI 模型完成拆解。
4. Whisper base 模型首次使用时自动下载到 data/models，约 150 MB；之后可离线复用。临时视频在处理完成后删除。
5. 拆解完成后点击“仿写”，填写本次时长、口吻、行业和转化要求。
6. 处理期间会持续显示解析、下载、Whisper加载、口播识别、AI拆解或AI仿写阶段、已用时间及取消按钮。
7. 拆解成功后自动进入左侧“爆款素材库”，避免刷新视频库后找不到结果。

爆款素材库支持按标题、行业关键词或标签搜索，并可查看Markdown存档、继续仿写、编辑标签备注或移出素材库。
8. 点击素材操作栏中的“下载无水印视频”，选择保存位置后开始下载。完成弹窗可直接播放视频或打开所在文件夹。
9. 同一素材下载成功后会记录本地路径；再次点击下载按钮时，可选择“重新下载”或“打开所在文件夹”。如果文件已被移动或删除，软件会自动恢复为普通下载流程。

六、客户与规则
- 客户池中的长用户 ID 和原评论默认缩短显示。操作栏图标依次用于查看详情、访问主页和修改状态。
- 视频标题默认缩短显示，鼠标悬浮可查看完整标题。作者和点赞数来自真实搜索页；无法可靠读取的收藏数、评论总数显示为“—”。操作栏图标用于查看详情、查看原视频和“拆解与仿写”。
- 拆解结果先以 Markdown 页面展示，用户可在结果页继续仿写；仿写结果同样支持 Markdown、复制和外部链接。
- 意向规则页面顶部只保留添加规则，编辑、启用/停用和删除均位于每行操作栏；新任务会使用当前启用规则。

七、数据与合规
- 软件只处理公开可见数据，不自动私信、不自动加好友。
- 评论中的手机号和微信号会默认脱敏。
- 请遵守平台规则、个人信息保护法及适用法律，仅用于合法业务场景。
- 抖音登录状态不会写入发布包，由使用者自行登录并加密保存在本机。
- 本地接口仅监听 127.0.0.1，其他电脑无法访问，因此不要求用户设置本地接口密码。

八、常见问题
- 如果旧版本出现 HTTP 408，请使用 1.1.1 或更高版本。1.1.1 已修复中文目录下 HTTPS 证书路径不兼容的问题。
- 同一账号的搜索串行执行，短时间重复搜索会自动排队。遇到验证码、异常跳转或无法识别的空页面时会停止重试并进入保护期，请在专用浏览器窗口人工处理后再试。
