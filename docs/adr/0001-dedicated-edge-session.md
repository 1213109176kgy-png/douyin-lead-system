# ADR-0001：使用专用持久浏览器会话

## 状态

已接受，2026-09-30。

## 背景

原搜索链路使用隐藏的 Qt WebEngine 页面，并固定覆盖浏览器 User-Agent。登录 Cookie 虽然能够保存，
但浏览器运行环境、缓存和页面脚本状态与用户实际登录环境并不完全一致。搜索失败时连续重载也会放大异常。

## 决策

- 使用 Playwright 优先驱动系统安装的 Microsoft Edge；Edge 不可用时自动使用发布包内置 Chromium。
- 登录和搜索共用应用专属的 `data/douyin-edge-profile` 用户资料目录。
- 浏览器窗口保持可见，验证和重新登录必须由用户完成。
- 一个账号只运行一个搜索任务；两次搜索至少间隔 35 秒。
- 检测到验证码、异常跳转或无法解析的空页面后停止任务，并进入 20 分钟本地保护期。
- 不实现随机设备指纹、代理轮换、验证码绕过或快速自动重试。

## 结果

优点是有 Edge 时直接复用系统浏览器运行时，没有 Edge 时也能由内置 Chromium 兜底；Cookie、本地存储和缓存能够稳定复用，用户也能看到真实页面状态。
代价是首次使用必须在专用浏览器窗口重新登录，采集时会显示浏览器窗口，发布包体积也会因内置 Chromium 增大。

## 故障处理

- Edge 未安装或无法启动：自动切换到内置 Chromium。
- Edge 与内置 Chromium 都无法启动：任务停止并提示重新安装软件。
- 专用资料目录被占用：任务停止，提示关闭已有采集窗口。
- 登录失效：停止任务，要求重新登录。
- 页面验证或异常：触发保护期，不自动绕过。
- 页面结构变化：明确报告“无法识别视频列表”，不把空数据写成成功结果。
