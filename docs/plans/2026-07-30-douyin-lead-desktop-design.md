# 抖音获客系统桌面版设计

## 产品边界

构建 Windows x64 绿色免安装、单人本机使用的抖音获客系统。用户解压后双击启动，首次填写 APIServer 订单授权号；应用自动管理本地服务、SQLite 数据、采集任务、客户池、规则、导出和备份。只处理公开资料，不绕过访问控制，不自动私信。

## 架构

采用 PySide6 桌面界面、SQLite 本地数据库和现有 APIServer v5.3.1 后台。桌面进程负责配置、任务编排、评分、去重与导出；APIServer 作为受控子进程监听 `127.0.0.1`。授权号用 Windows DPAPI 加密后保存在 `data/settings.json`，日志永不输出授权号、Cookie 或代理密码。

## 页面

工作台、获客任务、客户池、视频库、意向规则、任务记录、数据导出和系统设置。采集流程为：搜索视频、跳过已扫描视频、分页采集评论、规则评分、用户去重、保存证据、达到目标停止、导出 Excel。

## 发布

PyInstaller 生成目录模式绿色版，打包 Python/PySide6、客户端、APIServer 和运行资源。用户数据始终写入可执行文件同级 `data/`，方便复制备份和删除卸载。
