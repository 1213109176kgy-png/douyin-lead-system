# 开源抖音接口替换说明

项目已用 `tamnd/douyin-cli` v0.1.1（Apache-2.0）替换原订单号接口。
桌面程序启动 `server/douyin-local.exe serve --addr 127.0.0.1:8001`，并通过
`DOUYIN_COOKIE` 环境变量把当前用户在软件内完成的抖音登录会话传给本地服务。
关键词搜索不再使用独立 HTTP 接口，而是通过 Playwright 优先驱动系统安装的 Microsoft Edge；
系统没有 Edge 或 Edge 无法启动时，自动切换到发布包内置的 Chromium。两者使用本程序专用的持久化用户资料目录完成登录和搜索。
浏览器窗口保持可见，Cookie、本地存储和缓存跨启动复用，但不会读取用户的个人浏览器资料。
视频评论仍由本地服务按当前登录 Cookie 获取。

搜索采用单任务串行、最小时间间隔和异常熔断策略。验证码、异常跳转或页面结构无法识别时立即停止，
不进行代理轮换、随机设备指纹、验证码绕过或连续快速重试。

当前二进制基于 commit `fb1c9a1d4cc93de1566dc4fa23499825e377c223` 构建，
本地补丁只包含两点：在客户端配置中增加 Cookie；请求抖音网页 API 时加入
`Cookie` 请求头。不要把真实 Cookie 写进代码、日志或 Git。

抖音的视频详情和评论接口仍有平台自身的登录、频率和风控限制。这个替换移除的是
MoreAPI 订单授权和设备数量限制，并不承诺绕过抖音平台的访问控制。

上游源码与许可证：https://github.com/tamnd/douyin-cli
