# v1.2.7

## 视频拆解修复

- 修复图文、静音或无音轨视频在 Whisper 口播识别阶段出现 `tuple index out of range` 的问题。
- 没有可识别音轨时，软件会自动跳过口播识别，并根据真实标题和已采集信息继续拆解。
- 修复“AI 测试连接成功，但视频拆解仍提示配置 API”的问题。
- 点击“测试 AI”时会同步保存 API 地址、API Key、模型名称、温度和提示词；拆解线程读取的配置与测试连接保持一致。
- 与无音轨无关的文件损坏或模型异常仍会正常报错，方便定位真实问题。

## 验证

- Windows 正式打包环境自动化测试：36 项全部通过。
- 正式绿色包已验证包含无音轨回退逻辑和 AI 配置同步逻辑。
